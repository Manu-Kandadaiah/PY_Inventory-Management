# Fictional pySupply datasets

This folder contains sample CSVs generated from synthetic records. Every person, supplier and purchase order is fictional. All employee emails use `firstname.lastname@pysupply.com` and aren't used to send messages.

The application's linked inventory is created afresh with `python setup_project.py` or `python seed.py` after setup. The database file is intentionally excluded from GitHub to avoid publishing accounts and secrets.
